ACCESSIBILITY

Accessibility Decisions

Accessibility was considered during the design and development of this prototype.

1. Semantic HTML

I used semantic elements such as <header>, <nav>, <main>, <section>, <article> and <footer>.

These elements give the page a meaningful structure and make the content easier to understand.

2. Clear Navigation

The main navigation is kept consistent across all pages. This helps users know where they are and how to move between pages.

3. Skip Link

A "Skip to main content" link was added so keyboard users can move directly to the main content without repeatedly going through the navigation.

4. Clear Form Labels

Every important form field has a label. This makes it clear what information the user should enter and supports users who use assistive technologies.

5. Readable Colour and Text

The website uses clear text and background combinations. Text is also separated into headings and paragraphs to make the content easier to scan.

6. Keyboard-Friendly Controls

Normal HTML links, buttons and form controls are used so users can interact with the website using a keyboard.

Our goal

The goal is to make the website simple to understand, simple to navigate and usable by as many students as possible.
